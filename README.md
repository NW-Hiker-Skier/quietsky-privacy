# Quiet Sky — Privacy Policy & Terms

Live at:
- Official Privacy Policy: https://getquietsky.app/Privacy
- Legacy privacy URL redirect: https://nw-hiker-skier.github.io/quietsky-privacy/
- Terms: https://nw-hiker-skier.github.io/quietsky-privacy/terms.html

This public repo hosts a legacy **Privacy Policy** redirect (`index.html`) and the
**Terms of Use** (`terms.html`) for the Quiet Sky Android app, served via GitHub Pages.

Design: dark navy canvas (`#0C1A2A`) + sunset-gradient brand mark, Inter typography —
matching the Quiet Sky app's brand system. CSS is inlined in each file; `.nojekyll`
keeps Pages serving the raw HTML (no Jekyll theme).

The canonical privacy policy now lives at `https://getquietsky.app/Privacy`; this
repo's `index.html` should remain a redirect rather than a duplicate copy. The terms
source text lives in the main (private) app repo at `docs/TERMS.md`. When terms change,
update `terms.html` and push; Pages redeploys automatically.
